# 🏆 Bracket List Tournament

A modern, mobile-responsive Esports Tournament Management System. Built to effortlessly create, manage, and display professional bracket trees with a stunning dark neon UI.

## 🌟 Key Features

### 🎮 For Users
* **Interactive Bracket Viewer:** Beautiful horizontal-scrolling tournament brackets.
* **Modern UI/UX:** Glassmorphism design, AMOLED dark mode, and neon accents built with Tailwind CSS.
* **Real-time Status:** Track tournaments as Upcoming, Live, or Completed.
* **Account System:** Secure user registration, login, and profile management.
* **Asset Protection:** Built-in scripts to disable right-click, image dragging, and source-code inspection.

### ⚙️ For Administrators
* **Secure Dashboard:** Dedicated admin login and management panel.
* **1-Click Tournament Creation:** Automatically generate brackets for 4, 8, 16, or 32 teams.
* **Smart Match Progression:** Set match winners, and the system automatically advances them to the next round.
* **Custom Team Assets:** Upload and display individual team logos.
* **Automated Setup:** Built-in `install.php` script handles complete database and folder setup automatically.

## 🛠️ Technology Stack
* **Frontend:** HTML5, Tailwind CSS, Font Awesome.
* **Backend:** Core PHP (Vanilla, PDO).
* **Database:** MySQL.
* **Architecture:** 100% server-side rendered (No AJAX, no external JS frameworks).
